# Scam Weather

Межбанковский обмен предупреждениями о новых волнах мошенничества. Банк A подтверждает случай BEC и предупреждает о счёте получателя. Банк B, в котором открыт счёт, раньше получает повод для расследования. Банк C может направить следующий перевод на этот счёт на проверку до списания по собственной политике.

Проект для CIS Sprint. Стенд в `main` воспроизводит обмен между A и B на синтетических данных. В продуктовой истории банк C иллюстрирует следующего участника. Для пилота достаточно двух банков. По коммерческой гипотезе отправляющий банк спонсирует пилот, принимающий пробует входящие сигналы без платы платформе и измеряет эффект для своего антифрода. Devin помогает написать и протестировать коннектор.

## Как начать

Запустите стенд по инструкции. На экране покажите публикацию в A и локальную проверку перевода в B. Подключение C покажите отдельным артефактом с адаптером и тестом.
