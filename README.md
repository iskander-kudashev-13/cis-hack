# Scam Weather

Межбанковский обмен предупреждениями о новых волнах мошенничества. Банк A публикует подтверждённый сигнал с ограниченным сроком действия. Банк B получает его до списания и направляет совпавший перевод на проверку по своей политике.

Проект для CIS Sprint, трек Protect the little guy. В первом сценарии предусмотрены синтетические данные и два симулятора банков.

- [Бриф и план разработки](docs/SCAM-WEATHER-BUILD-BRIEF.md) — сценарий демо, контракт сигнала, API, задача для Devin и критерии приёмки.
- [Британские прецеденты](docs/UK-INTERBANK-FRAUD-EVIDENCE.md) — Pay.UK, Cifas и другие источники.

## Как начать

Сверьте контракт v1 и три прогона демо: до сигнала, после сигнала и после отзыва. Затем параллельно начните сервис доставки и интерфейс по брифу, а Devin передайте задачу на коннектор банка B из раздела 5.
