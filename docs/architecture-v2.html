Scam Weather · версия после ревью банковской инфраструктуры

Архитектура Scam Weather

Исполненный SWIFT-перевод остановить нельзя, поэтому сигнал описывает счёт, а не платёж. Hub рассылает сигналы заранее и не стоит на пути перевода: банк сверяется с локальной копией и не задерживает pacs.008.

Где сеть успевает вмешаться

Трансграничный перевод на счёт дропа X. Сплошные стрелки — сам платёж, пунктир — сигналы Scam Weather.

Компоненты

Решения о платеже принимает код банка. Hub только доставляет, Devin только пишет код до деплоя.

В контуре каждого банка

Коннектор (узел)

  • Отправка: HMAC счёта, подпись Ed25519, шифрование под группу
  • Приём: сам забирает сигналы из Hub, проверяет подпись
  • Локальный кэш действующих сигналов
  • Сверка платежа с кэшем, хук в антифрод банка
  • Политика банка: что делать с каким сигналом
  • Ключи в HSM банка
Наш SaaS

Hub

  • Банки подключаются сами по mTLS, входящие порты не нужны
  • Очередь шифротекстов, расшифровать не может
  • Журнал с цепочкой хэшей и подписанные ACK
  • Реестр участников и их публичных ключей
  • Не стоит на пути платежа: если он недоступен, банки работают с последним кэшем
Design-time

Devin

  • Запускается через API, когда банк выпускает новую версию схемы
  • Пишет и обновляет коннектор под формат банка
  • Пишет тесты по общему контракту и карточкам кейсов
  • Возвращает инженеру банка черновой PR с результатами тестов
  • Не видит живые данные и не участвует в решении о платеже

Проверка платежа без Devin

  • Банк А подтверждает инцидент
  • →
  • Коннектор А отправляет минимальный сигнал
  • →
  • Hub доставляет его банку Б
  • →
  • Коннектор Б сопоставляет сигнал с локальным платежом
  • →
  • Антифрод банка Б решает, нужна ли проверка

Когда банк выпускает новую версию схемы, Scam Weather запускает сессию Devin через API и возвращает инженеру черновой PR с обновлённым коннектором и результатами тестов. В демо этот шаг выполняется в Devin вручную: нужны тестовый репозиторий, согласованная схема и синтетические примеры.

Подробности в репозитории: docs/ARCHITECTURE.md, кейсы в bec-cases/, история изменений в CHANGELOG.md.
